# 我烧了 5.4 亿 Tokens，给自己做了个网格交易工具

（公众号发布稿 v2 · K3 视角 · 普通人叙事 · 截图在 docs/screenshots/wechat/）

---

7 月 17 日，Kimi K3 发布。

2.8 万亿参数、全球最大开源模型、前端编程榜单全球第一——压过了 GPT-5.6 Sol 和 Claude Fable 5，这是开源模型第一次在这个榜单上赢过所有海外闭源模型。

刷屏的测评我看了很多，但真正打动我的不是跑分，是一个念头：**如果它真的这么能干了，那我那些"早就想做、一直做不成"的东西，是不是都有戏了？**

当天开通了 Kimi Coding Plan。一个月后，我有了答案——

## 先报个账

这一个月，烧了 5.4 亿 Tokens，做出了一个网格交易工具：估值雷达、回测、压力测试、每日盯盘提醒、AI 研判，macOS / Windows 双平台打包，完全开源。

本地会话日志里一笔一笔都记着：1177 次请求，537,190,106 个 Tokens，按 API 刊例价折算大约 ¥600。统计脚本也一并开源了，谁都可以在自己电脑上验证自己的用量。

【插图：docs/screenshots/wechat/token-stats.png】

在这一个月里，我的角色是"产品经理 + 测试 + 首席挑刺官"。

## 为什么做这个

作为长赢指数投资的忠实读者，说小迷弟也不为过。E大的推文我一篇不落，网格策略那三篇更是翻来覆去读了不知道多少遍——低估开网、震荡套利、不死品种、高估收网，我自认是读懂了。

【此处插入：长赢指数投资公众号名片 + 网格交易三篇文章链接（作者自行补充）】

但读懂和执行之间隔着十万八千里：该买的时候在开会，该卖的时候忘了挂单，网格的 Excel 表格永远停在三个月前。😂

放在以前，"自己做一个"只是想想，因为时间的缘故也好，因为精力的原因也好，总之就是想想；而现在，几句话就把它做出来了。

## 直接看效果 👇

打开"今天"页，该做什么一目了然：今日待办、破网/高位/估值预警、机会精选，网格有没有在安静工作，一眼就知道。

【插图：docs/screenshots/wechat/today.png】

开网之前先算最坏情况：每格的买卖价、金额、份额、这一网赚多少全部算死；满格要多少钱、那一刻浮亏多少，摆在明处。回测直接标出历史上每一次的买点和卖点。

【插图：docs/screenshots/wechat/planner-full.png】

估值雷达持续监控几十只指数：分位超过 50% 亮红灯暂停买入，70% 只卖不买，80% 建议收网——高估的时候它提醒我收网走人，而不是抱着网格坐过山车。

【插图：docs/screenshots/wechat/picks.png】

功能上几个我满意的地方：

1️⃣ **等金额 / 等份额双模式**。等金额是 E大网格的原始口径，越跌买得越多；等份额越跌花的钱越少，高位开网自带仓位保护。规划页一键切换。

2️⃣ **参数寻优不只看收益**。25 组格距×格数在历史行情上回测，按"收益 − 0.45×回撤"打分，成交太少的标"低活性"——那更像抄底，不是网格。

3️⃣ **AI 只做研究助手**。接任意 OpenAI 兼容端点，会用自然语言解读估值、体检计划、研判该不该收网，但被严格限制不提供买卖指令。工具帮我执行纪律，不替我胡思乱想。🤝

## 诚实地说，AI 不是许愿机

烧掉的 Tokens 里，至少三成是学费：

它写出过口径错误的回测——我发现"这只票明明可以套利更多次"，追查到底才修正；它做的估值地图互相遮挡——我用截图怼回去改了三轮；它一本正经地漏掉功能——搜索框写着"如 510300"，按代码却永远搜不到，这个 bug 是我用出来的，不是它测出来的。

发布流水线连挂三次（YAML 语法、空目录、Token 权限），第四次才通过。macOS 签名公证那晚，看着 CI 日志跳出 "Accepted"，我一个没做过 macOS 开发的人，发布了一个苹果公证过的应用——那种感觉很不真实。🚀

大模型时代的真相是：**代码的成本崩塌了，判断的成本凸显了**。策略口径对不对、阈值合不合理、功能该不该做，AI 都会给答案，但每个答案都需要你接住、验证、负责。

## 写在最后：这个时代最大的礼物是"可能性"

先有投资逻辑，才有这个工具；工具做好之后，反过来帮我守住纪律、减轻盯盘负担。

但这一个月我收获最大的不是这个工具，是一种体感：**大模型时代，做成一件事的门槛，从"你会不会"变成了"你想不想"。**

这个项目里的大部分环节，我其实都不熟。放在以前，"不熟"就是大多数想法的终点——不是不想做，是掂量一下要补的东西太多，算了。这次的区别是，"不熟"没有变成"算了"，只是变成了多问几轮。

烧 Tokens 不是消费，是杠杆。几百块钱买到的不只是一个工具，还有一种"想到就能做"的自由。🏄

如果你也有那种"早就想做但一直没做"的东西——现在可能是它成本最低的时候。
