# 我烧了【X】万 token，给自己做了个网格交易工具

（微信公众号初稿 v2 · "AI 时代个人开发"视角 · 发布前替换【】内容）

---

先报个账：这个工具从头到尾，我一共烧了大约【X】万 token，折合人民币【Y】元。

如果三年前你说想做这样一件事——有估值雷达、有回测、有压力测试、能盯盘提醒、还能让大模型帮你研判该不该收网的一个桌面软件——正常的路径是：学半年 Python，再写三个月，中间放弃两次。

而我只用了【Z 个晚上/周末】。因为我几乎没有亲手写几行代码，写代码的是 AI。

## 起因：一个执行拉胯的 E大读者

我是长赢指数投资的读者。E大的网格策略——低估开网、震荡套利、不死品种、高估收网——我自认是读懂了的c。但读懂和执行之间隔着十万八千里：该买的时候在开会，该卖的时候忘了挂单，Excel 表格永远停在三个月前。

我缺的不是理念，是执行理念的基础设施。市面上没有合意的，那就自己做一个——放在以前这只是想想，现在真的可以。

## 过程：我和 AI 是怎么分工的

我的角色是**产品经理 + 测试 + 首席挑刺官**，AI 的角色是整个开发团队。

我给它讲的是策略，不是代码："网格要等金额，份额按 100 股整手取整""卖出价要和上一格买入价严格重合""高估区的品种要提示收网"。它负责把这些翻译成 FastAPI 后端、SQLite 表结构、前端页面，外加 127 个单元测试。

真实的过程当然不是一键生成。挑几个片段：

- **它确实会翻车**。发布流水线连续挂了三次：YAML 语法错、空目录没打包进去、Token 权限只读。每一次都是我把报错丢回去，它定位、修复、再跑，第四次通过。
- **它也会一本正经地漏功能**。搜索框明明写着"如 沪深300 / 510300"，但按代码搜索从来搜不到——它只匹配了名称和基准文本，忘了匹配代码字段。这个 bug 是我作为用户用出来的，不是它测出来的。
- **最神奇的一晚**是 macOS 签名公证。Apple 的证书、公证、staple 那套流程出了名的繁琐，我照着它和文档配好密钥，看着 CI 日志里跳出 "Accepted" 的时候，有种不真实的成就感——我一个没做过 macOS 开发的人，发布了一个苹果官方公证过的应用。

127 个测试全绿，双平台安装包自动构建，打开就能用。这是【X】万 token 换来的东西。

## 它到底是个什么工具

（这段从简，读者来看故事的，不是来看说明书的）

一个本地运行的网格策略执行工具：估值雷达告诉你什么时候能开网；档位表和压力测试让你先算最坏情况再掏钱；每天列出该挂的单子；涨出网格、跌破网格、估值进高估区都会预警；复盘页记录每一次套利回合和每一次"该执行没执行"。

完全开源，数据不出本机，macOS / Windows 都有打包好的版本。

## 诚实地说，AI 不是许愿机

烧掉的 token 里，我觉得至少三成是学费：它写出过看似合理但口径错误的回测（被我发现"网格明明可以套利更多次"追查到底），做出过互相遮挡的界面（被我用截图怼回去改了三轮），也给出过需要我否决的建议——比如它一度想把手续费计入回测，那是我的策略偏好问题，不是对错问题。

AI 时代的真相是：**代码的成本崩塌了，判断的成本凸显了**。什么是对的策略口径、哪个阈值合理、这个功能该不该做——这些 AI 都会给答案，但每个答案都需要你接住、验证、负责。它不替你思考，它只是让"思考完就能做出来"变成了可能。

## 一些真实的感慨

- 一个人 + AI，现在真的能做出"团队级"完成度的东西：测试、CI、签名公证、自动更新提醒，这些以前是小公司才有的工程能力。
- 瓶颈从"会不会写代码"变成了"知不知道要做什么"。对自己的需求想得越清楚，AI 的产出就越惊人——这大概是这个时代最值得练习的能力。
- 烧 token 这件事，我现在的理解是：它不是消费，是杠杆。【Y】元买到的不只是一个工具，还有一个随叫随到的开发团队，和一种"想到就能做"的自由。

如果你也有那种"早就想做但一直没做"的东西——现在可能是它成本最低的时候。
