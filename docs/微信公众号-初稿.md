# 我给自己做了一个 E大网格策略的执行工具

（微信公众号初稿 · 目标 2500 字内 · 发布前请通读替换【】中的个性化内容）

---

大概半年前的一个交易日，【某只我盯了很久的 ETF】跌到了我网格里早就标好的买入价。那天我在开会，没看盘。等晚上想起来，价格已经弹回去了三个点。

这不是第一次了。翻一翻我的 Excel 网格表，类似的"该买没买、该卖没卖"几乎每个月都有。更狼狈的一次，【某个品种】其实早就涨出了网格上沿，我的表格还停在三个月前的状态，仓位就那么晾着，既没吃到趋势，也没做成套利。

我是长赢指数投资的读者。E大的网格理念我自认是读懂了的：低估开网、震荡套利、不死品种、高估收网。但读懂和执行之间，隔着行情软件、Excel 表格和我的记忆力——它们各自为战，从来不在同一个地方。

后来我想明白一件事：我缺的不是理念，是执行理念的**基础设施**。于是我给自己做了一个工具，叫 ETFWorld。

## 它把网格的生命周期搬进了同一个地方

**开网之前，先回答两个问题：现在能开吗？最坏会怎样？**

"现在能开吗"不再靠感觉。系统持续监控一批指数的估值分位（【截图：估值地图】），分位超过 50% 的品种直接亮红灯——这是买入侧的否决线，和"低估开网"的原则严格对齐。

决定开网后，先看到的是档位表和压力测试【截图：规划页】：每格的买入价、卖出价、金额、份额、这一网赚多少，全部算死；满格需要多少资金、那一刻账面浮亏多少，也摆在明处。先算最坏情况，再决定开不开。

**开网之后，它替我盯盘。**

每天打开"今天"页，该挂的单子列得清清楚楚：哪个品种、买还是卖、什么价、多少份【截图：今天页待办】。涨出网格上沿、跌破网格下沿、估值涨过警戒线，都会变成预警卡。

退出也有了章法。估值分位 50% 是暂停买入，70% 是只卖不买，80% 是建议收网——高估的时候，它会提示我逐步卖出、关闭计划，而不是让我抱着网格坐过山车。

**事后，它替我复盘。**

每个品种套了多少回合、赚了多少价差、有几次该执行没执行，复盘页里一清二楚【截图：复盘页】。组合页回答的是另一个我最怕的问题：如果所有网格按计划买满，我的钱够不够？单一行业是不是押太多了？

## 几个我认真想过的设计

这不是一个把公式套进界面的工具，很多地方是把理念翻译成工程决策：

- **等金额与等份额并存**。等金额越跌买得越多、摊薄快、每网利润恒定，是 E大网格的原始口径；等份额越跌花的钱越少，适合在价格偏高、信心一般时开网——它自带仓位保护。规划页里可以一键切换。
- **参数寻优不只看收益**。25 组格距×格数在历史行情里跑回测，按"收益 − 0.45×回撤"打分，成交太少的组合会被标注"低活性"——那更像抄底，不是网格。
- **AI 只做研究助手**。接入任意 OpenAI 兼容端点，它会用自然语言解读估值、体检计划、研判该不该收网，但被严格限制"不提供买卖指令"。工具的职责是帮我执行纪律，不是替我胡思乱想。

## 开源，本地运行，数据不出本机

ETFWorld 完全开源（GitHub 搜索 ETFWorld，或文末"阅读原文"），所有数据保存在你自己的电脑上。不想折腾的话，直接下载打包好的桌面版（macOS / Windows）双击就能用；有代码能力的同学可以跑源码、改逻辑，按自己的想法长。

首次使用需要填入一个 Tushare Token 获取估值与行情数据，AI 研判功能可选配任意 OpenAI 兼容的模型服务。

## 最后，几句必须说的话

这个工具与 E大本人、长赢指数投资及任何社区**不存在官方关联**。理念归原作者，工具的实现、数据与结论由我自己负责。

它是研究工具，**不构成任何投资建议**。历史回测不代表未来收益。网格策略会破网、会长期套牢，工具能帮你守住执行的纪律，但纪律救不了错误的品种和错误的仓位——这些判断，永远是你自己的。

如果你也和我一样，理念都懂、执行拉胯，希望它对你有用。
