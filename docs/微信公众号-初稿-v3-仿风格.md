# 我烧了【X】万 Tokens，给自己做了个网格交易工具

（微信公众号初稿 v3 · 参考《我在 Codex 烧了 7.9 亿 Tokens》风格 · 发布前替换【】内容）

---

上个月，我在 Kimi Code 里烧了【X】万 Tokens，从零做出了一个网格交易工具：估值雷达、回测、压力测试、每日盯盘提醒、AI 研判，macOS / Windows 双平台打包，完全开源。

先汇报工程战绩 👇

**127 个单元测试全绿，CI 两分钟出双平台安装包，macOS 版带苹果官方公证（Notarized）——下载双击直接打开，没有"无法验证开发者"的警告。**

如果三年前做这件事，正常路径是：学半年 Python，写三个月代码，中间放弃两次。而这次，我几乎没亲手写代码。写代码的是 AI，我是产品经理 + 测试 + 首席挑刺官。

## 为什么做这个

我是长赢指数投资的读者。E大的网格策略——低估开网、震荡套利、不死品种、高估收网——我自认读懂了。

但读懂和执行之间隔着十万八千里：该买的时候在开会，该卖的时候忘了挂单，Excel 表格永远停在三个月前。😂

市面上没有合意的工具。放在以前，"自己做一个"只是想想；现在，真的能做出来。

## 直接看效果 👇

每天打开"今天"页，该挂的单子列得清清楚楚：哪个品种、买还是卖、什么价、多少份。

【截图：今天页待办】

开网之前先算最坏情况：每格的买卖价、金额、份额、这一网赚多少全部算死；满格要多少钱、那一刻浮亏多少，摆在明处。

【截图：规划页档位表 + 压力测试】

涨出网格上沿、跌破网格下沿、估值涨进高估区，都会变成预警卡。70% 分位只卖不买，80% 建议收网——高估的时候它提醒我收网走人，而不是抱着网格坐过山车。

功能上几个我满意的地方：

1️⃣ **等金额 / 等份额双模式**。等金额是 E大网格的原始口径，越跌买得越多；等份额越跌花的钱越少，高位开网自带仓位保护。规划页一键切换。

2️⃣ **参数寻优不只看收益**。25 组格距×格数在历史行情上回测，按"收益 − 0.45×回撤"打分，成交太少的标"低活性"——那更像抄底，不是网格。

3️⃣ **AI 只做研究助手**。接任意 OpenAI 兼容端点，会用自然语言解读估值、体检计划、研判该不该收网，但被严格限制不提供买卖指令。工具帮我执行纪律，不替我胡思乱想。🤝

## 诚实地说，AI 不是许愿机

烧掉的 Tokens 里，至少三成是学费：

它写出过口径错误的回测——我发现"这只票明明可以套利更多次"，追查到底才修正；它做的估值地图互相遮挡——我用截图怼回去改了三轮；它一本正经地漏掉功能——搜索框写着"如 510300"，按代码却永远搜不到，这个 bug 是我用出来的，不是它测出来的。

发布流水线连挂三次（YAML 语法、空目录、Token 权限），第四次才通过。macOS 签名公证那晚，看着 CI 日志跳出 "Accepted"，我一个没做过 macOS 开发的人，发布了一个苹果公证过的应用——那种感觉很不真实。🚀

AI 时代的真相是：**代码的成本崩塌了，判断的成本凸显了**。策略口径对不对、阈值合不合理、功能该不该做，AI 都会给答案，但每个答案都需要你接住、验证、负责。

## 写在最后

先有投资逻辑，才有这个工具；工具做好之后，反过来帮我守住纪律、减轻盯盘负担。

一个人 + AI，现在真的能做出"团队级"完成度的东西：测试、CI、签名公证、更新提醒——以前这是小公司才有的工程能力。瓶颈从"会不会写代码"变成了"知不知道要做什么"。对自己的需求想得越清楚，AI 的产出就越惊人。

烧 Tokens 不是消费，是杠杆。【Y】元买到的不只是一个工具，还有一个随叫随到的开发团队，和一种"想到就能做"的自由。🏄

如果你也有那种"早就想做但一直没做"的东西——现在可能是它成本最低的时候。
