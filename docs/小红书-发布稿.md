## 正文

一个月前 Kimi K3 发布，前端编程榜全球第一。
我当天就开了 Coding Plan，就一个念头：
那些"早就想做、一直做不成"的东西，是不是有戏了？

今天来交作业 👇

🔥 1177 次请求
🔥 537,190,106 个 Token（约 5.4 亿）
🔥 折算 API 刊例价 ≈ ¥600

本地日志一笔一笔都记着，统计脚本开源了，谁都能在自己电脑上验证。

做的是什么：一个网格交易辅助工具。
估值雷达 / 回测 / 压力测试 / 每日提醒 / AI 研判，
macOS、Windows 都能直接用，完全开源。

这一个月我的角色：产品经理 + 测试 + 首席挑刺官 😂

AI 真不是许愿机，说三个它翻车的瞬间：

❌ 回测口径算错，我发觉"这只票明明能套利更多次"，追查到底才修对
❌ 界面数字互相遮挡，我截图怼回去改了三轮
❌ 搜索框写着"如510300"，按代码搜却永远搜不到，这 bug 是我用出来的

但也有高光时刻：
macOS 签名公证那晚，看着日志跳出 "Accepted"，
我一个没做过 macOS 开发的人，发布了一个苹果公证过的应用 🚀

说白了，AI 把"做东西"这件事变便宜了，
但想明白要做什么，还是得靠自己。

以前"不会"就是想法的终点，
现在"不会"只是多问几轮。

如果你也有早就想做的东西，现在可能是它成本最低的时候 🏄

GitHub 搜 ETFWorld，地址放评论区。
